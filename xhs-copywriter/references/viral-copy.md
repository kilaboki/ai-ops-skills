# 涨粉与爆品文案 + 运营方法（工作流·阶段二·结构）

> 优先级低于 Agent 系统提示词；Agent 已规定语气/口吻/品牌词时，本节只管"结构与运营方法"。

## 一、标题（≤20 字，核心词放前段）

- 平台硬约束：标题约 **20 字**上限，**前 10–16 字权重最高**（列表页只显示前约 12 字），钩子必须在前段。
- 数字比形容词有力；奇数比偶数略好（"7 个"比"6 个"）；精确比模糊可信（"180 天"比"长期"）。
- 8 个可套句式（句式是骨架，词换成自己的）：
  1. 数字+痛点+结果：`3 个技巧，让____少踩坑`
  2. 人群+场景+利益：`____必看｜____`
  3. 痛点+解决：`____怎么办？这 3 招亲测管用`
  4. 反差/反常识：`别再____了！过来人劝你避开这 5 个坑`
  5. 提问式（吃搜索）：`____怎么选？看完少花____`
  6. 时间/稀缺（仅真实才用）：`2026 最新版｜____流程`
  7. 实测对比：`____ vs ____，实测差距在这`
  8. 清单/抄作业：`N 条____，照着做就行`
- 一条标题只用一个句式；不堆词、不做"假装发现秘密"式骗点击。

## 二、正文结构（按目的选骨架）

通用三段：**首段钩子 → 分点主体 → 结尾行动**。
- 首段（前 2–3 行/前 100 字）：场景 / 痛点 / 结果 / 反差，**直接切入**，不写背景铺垫；自然带入核心关键词一次。
- 主体：分点，每点一个信息增量；每点建议 ≤3 行；干货尽量做成可收藏的清单。
- 结尾：给**一个**今天能做的动作 + 一个开放式提问（见第五节）。

按桶微调：
- 干货/教程：清单化，编号可少用（见 humanize，避免太整齐）。
- 测评/对比：先给结论再讲过程；列"适合谁/不适合谁"。
- 故事/经历：第一人称按时间线，落一个具体瞬间。
- 避雷：坑→为什么是坑→怎么绕。

## 三、首段钩子（3 套写法）

- 痛点共鸣：`你是不是也____？`
- 亲身经历：`我前后试了 ____，才摸清 ____`
- 结果前置：`用这方法，我把 ____ 做到了 ____`
（具体写法与"别 AI 味"见 `humanize.md`。）

## 四、封面与图内文字方法

- 封面主标题 ≤12 字、字号大、缩略图 5 秒读得出；只放 1 个核心利益点。
- 高对比配色、留白不贴边；首图承担"点击"，内页承担"收藏/完读"。
- 首图讲钩子，第 2–3 张承接（目录/结论/对比），中间展开步骤参数清单，末张总结避坑并引导收藏。
- 图片比例统一、首选 3:4 竖版；别直接发横图（会被裁）。
（封面文字以"小图清楚可读"为准。）

## 五、互动 CTA（只引导站内动作）

引导收藏/评论/关注，但只站内的：评论区留言、收藏备用、关注看后续、搜账号。
- 收藏：`先码住，____时直接翻出来用`
- 评论：`你们更想看 A 还是 B？评论区说`、`你还踩过哪些坑？补充一下`
- 关注：`持续更新____，关注不错过`
（具体句式按 Agent 人设，本节只给"要有单一 CTA + 一个开放问题"的结构。）

## 六、流量机制（理解它才知道优化什么）

- 新笔记先入**小初始池**（冷启动），考核发布后**前 2–6 小时**数据决定是否进更大池。
- 互动价值排序（经验，方向可靠）：**收藏 / 评论 / 转发 / 关注 > 点赞**；完读率、停留、点击率是前置门槛。"只刷赞不涨收藏"进不了二次推流。
- 搜索流量占比高：关键词布局好可拿数月长尾。
- 这些数值平台未公开，一律以**自己创作者后台实测**校准，别当硬指标。

## 七、SEO 关键词布局（搜索流量）

- 埋词顺序：标题前段核心词 → 正文首段 100 字内自然出现 → 小标题/分点 → 图内文字 → 话题标签 → 作者自评补长尾。
- 长尾词公式 = `人群 + 场景 + 痛点`；7 成精力放长尾，避开大词红海。
- 自然密度，不堆砌重复。
- 话题标签：少而准——1 个大标签 + 2–3 个精准中长尾 + 1 个场景/自建；别堆泛标签。

## 八、发布节奏与起号方法

- 频率：新号冷启动每周数篇稳定更、别断更超 3 天；稳定期重质量，别盲目日更低质（会稀释互动率、触发低质限流）。
- 时段（经验）：工作日午 12–13:30、晚 18:30–22:30；周末 10–12、15–23。**最终以自己后台"粉丝活跃时间"为准。**
- 发布后黄金 1–3 小时：及时回评论、补一条作者自评带关键词。
- 数据差先改封面/标题或隐藏笔记，**别反复删除**（删笔记触发风控）。

## 九、新人起号误区（反向清单）

频繁跨赛道／只刷赞不看收藏／新号前几篇就发硬广／标题堆词正文叠词／只做推荐流不做搜索／数据差就删笔记／频繁改昵称头像简介／纯 AI 内容不标注·未报备合作·刷赞互暖。
