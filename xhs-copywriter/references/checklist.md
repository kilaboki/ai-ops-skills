# 成稿自查清单（工作流·阶段三）

> 写完按本清单核对。
> 优先级低于 Agent 系统提示词：与 Agent 规定的口吻/结构/格式冲突时，以 Agent 为准，本节只查"通用质量 + 去 AI 味 + 红线"。

## A. 红线自查（命中即改，对照 compliance.md）

- [ ] 有无极限词/绝对化：最、第一、唯一、顶级、100%、永久、根治、稳赚、保过。
- [ ] 有无站外导流：联系方式、二维码、外链、「私我/看主页/评论区领」及谐音/符号变体。
- [ ] 有无无资质功效、医疗/收益承诺。
- [ ] 有无编造的经历/数据/引语/案例；价格是否照资料口径、没造第四种说法。
- [ ] 有无点名贬低竞品、未报备合作、隐私/未成年人/敏感题材。
- [ ] 身份与口吻是否一致（品牌号没装素人、素人号没编经历）。

## B. 真人感自查（对照 humanize.md）

- [ ] 第一段是否直接进具体场景/动作/时间/结论，没背景铺垫。
- [ ] 是否有 ≥2–3 个**具体细节**：数字、时间、价格、地点、身体感受、过程。
- [ ] 是否有不完美：一处缺点/失败/犹豫/不确定（"也可能我…""因人而异"）。
- [ ] 有没有工整排比、总分总、编号小标题、每段等长——若有，打散改错落。
- [ ] 有没有空洞形容词/术语腔（显著、极具、赋能、全方位、打造、助力、开启、氛围感、治愈系、宝藏、绝绝子、天花板、闭眼入、谁懂啊、首先其次最后、综上所述、值得一提）。
- [ ] 有没有"解释自己"的句子（"这就是…的力量""这意味着…"）——有则删，写完那句就停。
- [ ] 结尾是否**不总结、不升华、不号召**，用后续/限制/反问/待验证收。
- [ ] 念一遍：像不像一个真人在跟具体某个人说话？不像就重写（句长是否错落、语气是否有起伏）。

## C. 结构与涨粉自查（对照 viral-copy.md / topic.md）

- [ ] 选题是否锁了单一赛道与具体人群（这条为什么有人会搜/会收藏）。
- [ ] 标题前段是否放核心词、是否一个清晰钩子、不堆词。
- [ ] 正文是否"先给什么—再给什么"清楚，分点每点一个增量。
- [ ] 有没有一个明确 CTA（引导收藏或评论或关注，只站内），结尾带一个开放问题撬互动。
- [ ] 有没有可被搜索的关键词自然埋入（标题+首段+分点）。
- [ ] 首图/封面文字是否 ≤12 字、单一利益点、缩略图可读，与正文主题一致。

## D. 判定与处理

- **A 红线项命中**：必改，改不动则该句不写（编造/导流一律删）。
- **B 真人感项命中**（排比/总-分-总/升华结尾/空洞词/无具体细节）：优先**局部重写问题段落**；若通篇信息组织就 AI（整段都工整、全篇无细节），**整段重写**，别只换词。
- **C 结构项缺失**：补对应件（补钩子/补 CTA/补关键词/补封面文字）。
- 改完只复测变动项，已通过的别反复重跑。

## E. 交付时附一行（不输出审核报告）

写完直接给文案成品；最多附 2–3 条**需人工确认的事实**（价格、授权、资质类），不要把本清单逐条复述给用户。需要正式发布级审核时，再走 `xiaohongshu-publish-review`。
