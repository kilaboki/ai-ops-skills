# 选题方法（工作流·阶段一）

> 优先级低于 Agent 系统提示词。选题前先确认 Agent 给的赛道、人群、品牌口径，本节只补"怎么选到能涨粉、能被搜到、有人看"的方法。

## 一、先锁三件事，再谈选题

选题前必须固定：**垂直赛道 + 精准人群 + 可提供的价值**。
- 公式：`细分领域 + 身份/场景 + 价值锚点`。例（通用）：职场 Excel + 0 基础转行政 + 每天省 2 小时做表。
- 反例：今天美食明天职场，账号标签乱，系统无法匹配兴趣向量，推荐越来越少。
- 同一账号选题尽量在 1 个垂类内轮转，跑出数据再扩相邻类。

## 二、选题从哪来（按可靠性排序）

1. **对标账号拆解**：选 5–10 个同赛道、近 30 天高赞藏账号，取它们赞藏最高的若干篇做样本池。
2. **站内搜索需求**：搜本赛道核心词，看下拉联想、"大家都在搜"、话题页高赞笔记标题——这些是真实搜索意图。
3. **评论区长尾**：爆款笔记评论区的提问/吐槽，是下一批选题金矿（"求个链接""那 XX 怎么办"）。
4. **热点 / 节日 / 季节**：与赛道能自然关联的才蹭，硬蹭伤号。

## 三、爆款复制方法（涨粉核心）

> 复制**结构**，不复制**文案**。
- 流程：拆爆款 → 提炼「人群 + 痛点 + 解决方案 + 封面结构 + 标题句式 + 互动钩子」→ 用**自己的真实素材/场景**重写，保留框架 → 同结构连测 3–5 个不同选题 → 跑出数据最高的再做 2–3 个变体拉成系列。
- 判"像不像爆款"的合格线（经验值，以自己后台校准）：图文点击率、收藏率、互动率、完读率明显高于账号均值。
- 数据体检改法：点击率低→改封面与标题；收藏率低→补可执行步骤/清单/模板；转粉率低→优化主页价值点与置顶。

## 四、选题分桶（按内容目的，便于轮换与归因）

| 桶 | 目的 | 涨粉/收藏倾向 |
|---|---|---|
| 干货教程 | 可收藏的清单/步骤 | 高收藏，涨粉主力 |
| 测评对比 | 决策帮助 | 高收藏+评论 |
| 避雷吐槽 | 情绪共鸣 | 高评论、转发 |
| 经历故事 | 人设与代入 | 高完读、转粉 |
| 求助互动 | 抛问题 | 高评论，撬互动 |
| 热点借势 | 流量风口 | 看时效，慎用 |

内容配比参考：约 7 成干货/测评/避雷 + 2 成故事/热点 + 1 成人设向，避免全是硬种草。

## 五、选题质量自检（命中越多越值得写）

- 有**信息差**吗（读者不知道的做法/价格/坑）。
- 有**情绪钩子**吗（焦虑/好奇/共鸣/反差/占便宜）。
- **人群**够具体吗（不是"大家"，是"刚开咖啡店的一个人看店老板"）。
- 有人**会去搜**吗（有对应搜索词）。
- 有**收藏价值**吗（能"先码住回头用"）。
- 今天就能给出**可执行**的一条动作或清单吗。

## 六、一条选题的产出格式（喂给阶段二）

```
选题：<一句话主题>
赛道/人群：<谁、什么场景>
钩子类型：<信息差/情绪/反差/干货>
核心关键词：<1 个长尾词，供标题与搜索埋词>
标题方向：<2–3 个候选句式>
正文骨架类型：<干货/测评/故事/避雷>
真实素材：<已掌握的时间/价格/数字/细节，缺则标注需补>
封面文字方向：<≤12 字核心利益点>
```

> 没有真实素材就先备齐（见 `humanize.md` 信息底稿），选题再顺，无东西可写也会写空。
