# 写时规避违规（安全方法 · 工作流·阶段二·红线）

> 思路：**边写边避开**，而不是写完再删。用正向、真实、具体的表述替代易踩线写法。
> 优先级：低于 Agent 系统提示词，且**低于项目品牌口径与平台规则**——更严的一方胜出。
> 发布前需要带官方规则基线、逐条分级、图片审核时，可选再调 `xiaohongshu-publish-review`；本节负责日常"写的时候不踩"。

## 一、高频红线与替换法（写这些之前先绕）

| 风险 | 别这样写 | 改成 |
|---|---|---|
| 绝对化极限词（广告法） | 最好、第一、唯一、顶级、国家级、100%、永久、根治、稳赚不赔、保过 | 我用了顺手、目前比较合适我的、效果因人而异、我的体验是 |
| 站外导流 | 微信号、手机号、QQ、邮箱、二维码、小程序码、外链、店铺地址、口令；「私我」「看主页」「评论区领」「懂的都懂」 | 只引导站内动作：搜账号名、评论区聊、私信问、收藏这篇 |
| 规避式写法 | 用符号/字母/谐音代敏感词（+v、V:、威信、薇信、谐音变形） | 直接不写联系方式；导流暗号本身是平台重点盯的不规范营销 |
| 功效/医疗 | 无资质写 治疗、消炎、祛痘、美白、祛斑、抗衰、降三高、改善睡眠 | 只写主观使用感受（上脸不刺激、不闷痘），不承诺功效 |
| 虚假夸大 | 编收入/学历/案例、伪造销量、虚构"亲测"、前后对比承诺 | 没有真实授权素材就不写经历/引语；写可核对的事实 |
| 价格促销 | 随意造价格口径、写"限时/秒杀/全网最低/免费送/券/满减"、暗示永久免费、虚假稀缺 | 价格只照项目资料原文，不换算不造第四种说法；稀缺只来自真实库存 |
| 贬低竞品 | 点名竞品、拉踩、竞品价格功能对比 | 只对比传统方式或泛化品类，不点名同行 |
| 诱导互动 | 点赞抽奖、关注领资料、不转不是 XX、道德绑架式话术 | 用真实信息价值换互动 |
| 未成年人/隐私 | 他人身份证/住址/病史/银行卡、未成年人形象商业化 | 不写，删细节 |
| 敏感题材 | 时政、灾难事故、维权曝光、性别地域对立、玄学命理、极端减肥 | 弱化对立与绝对结论，必要时不碰 |
| AI 与原创 | AI 生成不标注、搬运洗稿、盗用他人图 | 按平台要求标注 AI 辅助；用原创素材 |
| 商业合作 | 付费/置换伪装素人、未报备 | 按平台要求报备或标「合作/广告」 |

## 二、判断口径（别误杀正常表达）

- 普通分享的**主观感受**可留（"我觉得好用"）；**客观结论式断言**要改（"全网最好用"）。
- 真实体验可写；没有素材支撑的经历、数据、引语**不编**。
- 身份与口吻一致：**品牌号别装素人，素人号别编经历**（这是平台判违规/不推荐的核心，也最容易被 AI 踩）。

## 三、写前四问（落笔前过一遍）

1. 身份对吗？有没有装素人、编店主原话、编经历？
2. 有没有联系方式、二维码、站外链接或暗示话术？
3. 有没有绝对化、虚假数据、效果承诺、无资质功效、乱写价格？
4. 有没有点名竞品、未报备合作、隐私/未成年人/敏感题材风险？

## 四、与去 AI 味的协同（两处常打架，统一处理）

- "亲测/真实体验"：humanize 要代价感，compliance 要真实性。**只有真有素材才写体验**，没素材就只写体感或泛化（"不少小店"），二者不冲突。
- 极限词既违规又是 AI 腔（"最强/极致"）：**删掉换成具体事实**，同时满足 `humanize.md` 与红线。

## 五、与 Agent / 项目的优先级

- Agent 系统提示词或项目品牌资料给了更严口径（价格、可说范围、禁提项）时，**以那个为准**，本节只兜底通用平台红线。
- 拿不准的合规判断，宁可更严一档，并在交付时把需要人工确认的项（价格、授权、资质）单列。
