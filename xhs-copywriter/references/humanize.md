# 让文案像真人写（写作技巧 · 工作流·阶段二·语感）

> 目标：**生成那一刻**就写得像人，而不是写完再洗。
> 优先级低于 Agent 系统提示词：本节给"通用去 AI 味技巧"，但**人设、语气、口吻、口头禅、写作风格由 Agent 决定**；二者冲突时以 Agent 为准。

## 一、心法：人味的来源不是"删 AI 词"，是这三样

1. **具体经验密度**：有真人独有的细节（一次时间、一个价格、一种身体感受、一段过程）。
2. **不完美**：有犹豫、有偏见、有小毛病、有失败和后悔——不是端水测评。
3. **对具体的人说话**：给限制条件和"适合谁/不适合谁"，不是面向所有人安利。

> 空洞本身就是最强 AI 味。模型手里只有"卖点"没有"真实细节"时，再润色也是精致而假。

## 二、信息底稿（写前先备料）

动笔前先备 **≥3 条"只有作者本人知道"的信息**：一次具体时间/地点、一个数字或价格、一处身体感受或过程、一个失败/犹豫/踩坑。
- 凑不齐 3 条：**降断言**，只写体感（"我觉得还行"），**不编**功效、数据、销量、他人评价。
- 缺真实素材这件事，应回到选题/资料环节补，而不是硬写。

## 三、AI 指纹清单（写时规避，含改写对照）

| 维度 | AI 腔（✗） | 真人（✓） |
|---|---|---|
| 开头 | 今天给大家分享一个超好用的宝藏好物，真心推荐 | 挖到个小东西，我连着用了快两周 |
| 开头 | 有没有姐妹和我一样，一直被出油困扰？ | 我真的很烦脸一到下午就油光发亮 |
| 开头 | 在快节奏的都市生活中，越来越多的人开始追求松弛感 | 我周六早上 7 点被楼上装修吵醒，索性下楼坐了 20 分钟 |
| 句式 | 它质地清爽，吸收快速，肤感温和，性价比出众（工整排比） | 上脸不闷，吸收挺快，价格也不贵 |
| 句式 | 它不仅是一款产品，更是一种生活方式的表达 | 我买它就是因为瓶子好看，结果最常用的是盖子 |
| 结构 | 首先…其次…最后…（总分总/编号小标题） | 先说缺点：重。优点也有：不漏。过程放后面 |
| 段落 | 每段一样长、每段一个观点、没有过程感 | 一段 1 句，下一段 4 句，再一段 2 句 |
| 用词 | 极具、显著、十分、非常、诸多 | 用下来能感觉到变化，有几个点我挺满意 |
| 用词 | 依托缓释配方，长效维持肌肤稳态（术语堆砌） | 上脸没有一下子猛刺激，效果慢慢出来 |
| 标点 | 它——真的——很——好用！！！ | 好用。但重。我拎着走了 800 米手腕酸 |
| 结尾 | 希望这篇分享能帮到大家，一起变美吧 | 先这样，用空瓶再来说 |
| 结尾 | 总之这是一款值得入手的好物 | 我买的是 2 号，黄皮别学我 |

## 四、正向写作规则（写成什么样，比"别写成什么样"更重要）

- 第一段一句话直接进**具体场景 / 动作 / 时间 / 结论**，不铺垫背景。
- 用**具体名词**替抽象形容词：把"好看"写成"奶白、磨砂、盖子有点松"；把"好用"写成"不黏枕头、3 分钟吸收"。
- **动词优先**，形容词能换就换；少用"极致/全新/专业/优质/赋能/打造/助力/开启"。
- 至少一处**自我修正或不确定**："也可能是我手法不对""这点因人而异""我怀疑是那天出门早"。
- 至少一处**个人代价/缺点/吐槽**：包装留指纹、买错色号、忍了三天才习惯。
- 信息顺序可以**不那么理性**：真人想到哪说到哪，可先插一句无关小事再回到产品（"有序"本身就是强 AI 指纹）。
- 允许短句、半截话、追加补充、括号插话；不追求每句语法完整。
- **从不解释自己**：写完那句就停，不要补"这就是……的力量""这意味着……"。
- 结尾**不总结、不升华、不号召**，用"后续/限制/反问/待验证"收。

## 五、标点与节奏（去 AI 感的关键）

- 逗号用来切节奏；多用句号拆短句；少堆破折号、省略号、感叹号。
- 句长**错落**：刻意有 1 句成段的短，也有 1 句超过 25 字的长；别全篇等长。
- 语气有起伏，不是匀速夸赞；可以平淡、可以吐槽、可以犹豫。

## 六、AI 高频腔词（出现就换成具体说法或直接删）

赋能、闭环、抓手、底层逻辑、情绪价值、彰显、致力于、旨在、全方位、打造、助力、开启、共赴、无缝、至关重要、深入探讨、值得一提、随着…的发展、总的来说、综上、首先/其次/最后、宝藏、神器、天花板、绝绝子、YYDS、闭眼入、无限回购、谁懂啊、狠狠爱住、拿捏、氛围感、治愈系。
> 这些是"腔"，不是"词"——正式语境里的正常术语不必硬删；只删空泛、重复、装专业的。

## 七、与 Agent 人设的边界

- Agent 已规定口吻/人设/常用句式时，**按 Agent 的来**，本节技巧只在不冲突处补"去 AI 味"。
- 本节**不替 Agent 发明人设**，也不要求第一人称——是否用"我/你/我们"由 Agent 人设决定；本节只说：用了第一人称就带上真实代价与不确定，别写成客服腔。
