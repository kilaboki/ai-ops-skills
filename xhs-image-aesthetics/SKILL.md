# 小红书配图审美与高流量特征

本 skill 只回答一件事：**一张图作为视觉作品，什么样的会好看、会高点击、会高停留，好图有哪些可一眼对照判定的特征。** 它是「看图判好坏」的标准。

## 职责分工（各管一段，互不重叠）
- **本 skill**：好图的视觉标准——构图、焦点、色彩明度、信息密度、留白、缩略图可读、可信感、图上文字层级。
- **`seedream-prompt`**：怎么把图做出来（拍/修/AI 生成/提示词/负向词）。
- **`xhs-copywriter` 与 Agent**：某张具体图拍什么内容、选题。
- 与拍摄/生图 Agent 系统提示词、品牌视觉规范冲突时，以 Agent 为准。

## 上位标准（优先级高于一切细则）
> 在手机信息流的**缩略图尺度**下，用**最低认知成本**让目标人群一眼看懂"这是什么、为什么值得看"，并给出**可信**的审美或信息收益。
> 拆成一句话：**缩略图可读性 × 视觉效率 × 可信收益**。
> - 高点击 ≈ 缩略图能识别 + 留一点未知（钩子）。
> - 高停留 ≈ 有层次细节 + 信息递进，值得多看一眼。
> 凡增加理解成本、削弱真实感、分散注意力的元素，都在拖这张图的后腿。

## 三条贯穿的命门（三家交叉验证一致）
1. **先缩略图成立，再大图成立**：小红书图的第一现场是信息流里那个小缩略图；缩到拇指大小还认得出主体和主标题，才有点击。
2. **一个焦点、一个信息**：一张图只放一个主视觉/一个核心信息，"什么都想说"等于没说。
3. **可信 > 精致**：真实的光影、纹理、生活痕迹带来信任与停留；过度完美、模板感、促销堆砌反而触发"广告/假/划走"。
