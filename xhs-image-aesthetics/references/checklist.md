# 成图审美自检

选图/出图后逐项核对。这是"看图判好坏"，不涉及怎么制作。与 Agent/项目视觉规范冲突时以那个为准。

## 上位测试（最重要，先过这条）
> 缩略图尺度下，0.5–3 秒内能否让用户：① 一眼看懂**这是什么** ② 一眼知道**为什么值得看** ③ 感到**可信、有审美或信息收益**。
> 三件缺一件，再精致也是废图。

## 单图（对照 traits.md）
- [ ] 唯一视觉焦点，3 秒能指出来？
- [ ] 缩到拇指大小仍认得出主体、主标题、主色块？
- [ ] 主体与背景明度/色相对比够，缩略里跳得出来？
- [ ] 主色 ≤3、点缀 ≤1，色温统一？
- [ ] 信息不堆：首图核心元素 ≤3 组、有主次、有留白？
- [ ] 构图有主轴，主体没被边缘切断，水平线不歪？
- [ ] 光影/纹理/比例可信，不过曝不塑料？

## 封面（对照 cover.md）
- [ ] 有且只有一个视觉钩子（反差/特写/异常/结果感）？
- [ ] 不是"海报式塞三个卖点"，只放一个钩子？
- [ ] 文字少而大、不压主体、不堆贴纸边框？

## 一组图（对照 series.md）
- [ ] 色板/字体字重/版式网格/节奏/质感，每张都同一套？
- [ ] 内页按认知路径推进，不是各说各的或重复封面？
- [ ] 九宫格排开像一组、遮字仍统一、任两张并排不打架？

## 可信度（对照 authenticity.md）
- [ ] 没有触发"广告/假/凑数"信号：抠图悬浮、促销符号先行、模板边框、过度磨皮撞色、元素等权堆叠？
- [ ] 有可信收益：真实质感 + 取舍清楚？

## 文字（对照 legibility.md）
- [ ] 眯眼 1 秒读主标题；层级 ≤3；压图有底且对比够；文字不压主体关键部位？

## 处理
- 上位测试不过 → 多半是"这张图要承担什么信息"没想清楚（不是排版问题），回到定职能重做。
- 单项不过 → 按对应 reference 改（焦点/对比/密度/层级）。
- 改完只复测变动项，已过的别反复重跑。
