# 可信度信号：原生优质 vs 模板硬广 / 太假

这是**看图分辨**的信号——一张图会让人判断"真实可信"还是"广告 / 凑数 / 很假"而划走。对实拍、设计图、AI 图一视同仁，只讲"看起来可信吗"，不讲怎么做到（那是制作层）。

## 原生优质 / 可信的信号
- 画面有**环境上下文与使用痕迹**、合理的"不完美"。
- 光向统一，有**接触阴影/落地阴影**，物体"站得住"。
- 材质纹理、比例、透视可信；高光不过曝、不塑料。
- 装饰克制，贴纸/边框/箭头极少；文字少、作为补充、层级清楚。
- 信息有取舍，**先给视觉收益**，再给结论。

## 低质 / 模板感 / 硬广感 / 一眼假 的触发信号（命中即易被划走）
- 主体像**抠图悬浮**，没有接触阴影，背景与主体光不一致。
- **过度磨皮/锐化/过曝**、塑料高光、皮肤或产品丢失原生纹理。
- 高饱和撞色、脏渐变、每块颜色都在抢。
- 标准化模板边框、统一箭头、同款贴纸批量复用、素材库感强。
- 文字压满、多字体混用、发光描边、大色块标题。
- **促销符号先行**：价格贴、优惠券、满减、"赶紧/限时/必买"、强 CTA 按钮、二维码、联系方式——比画面还抢眼。
- 元素等权堆叠、产品居中+卖点罗列、构图刻板工整到僵硬（间距全等分）。
- 低清、重复水印、信息空泛（只有"绝了/必入"却无可验证细节）。

## 一条判据
> 真实感带来**信任**，信任带来停留与转化；"过度完美 + 模板 + 促销堆砌"会同时触发"假"和"广告"两个划走理由。
> 可信度 ≠ 画质高。一张光影合理、有生活痕迹、克制的图，比一张"精致但空、像货架海报"的图更容易被看完。

> 注：怎么修出/生成出"可信"的图（打光、后期、提示词、负向词）属制作/模型层（`seedream-prompt`），本 skill 只给"看图是否可信"的标准。
