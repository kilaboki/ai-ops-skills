# 封面（首图）：决定点击的那一张

封面是一张"缩略图作品"——标准是 **1 秒能识别主题，0.5 秒产生好奇**。坏封面 = 3 秒还看不出在看什么。

## 好封面 vs 会被划走的坏封面

| 要素 | 好封面 | 坏封面 / 划走信号 |
|---|---|---|
| 主体 | 单一主主体或单一主信息，占画面约 1/3–2/3，缩略仍清楚 | 多主体等权；主体 <1/5；缩略图只剩一团色块 |
| 焦点 | 唯一焦点，对比/清晰/面积最高，无同强度竞争 | 文字、背景、主体互相抢；第一眼无落点 |
| 背景 | 干净、少干扰、服务主体 | 杂物多、线条穿主体、贴边裁切、背景比主体花 |
| 对比 | 明暗或色相有明确反差，主体从底色里"跳出来" | 低对比、灰蒙、主体融进背景 |
| 文字 | 主标题 ≤2 行、字大少且可读、是层级的一部分；文字面积集中不铺满（首图字块建议 ≤画面 20–30%） | 文字多小密；标题压焦点；多字体混用；贴边 |
| 视觉钩子 | 有且只有一个：尺度反差 / 明暗反差 / 状态反差 / 局部特写 / 秩序中的异常 / 清晰结果感 | 无钩子，只有模板边框和装饰；信息平铺一眼看尽 |
| 色彩 | 克制、主色明确、点缀少、色温统一 | 高饱和撞色、脏色、每块都亮、渐变滥用 |
| 装饰 | 有功能、无多余贴纸边框 | 模板边框、贴纸、角标、发光描边堆叠 |
| 裁切 | 主体完整、裁切有意图、边缘不尴尬 | 切头切脚切关键、主体贴边、四边撞满 |
| 认知成本 | 一眼懂主题，留一点未知 | 一眼看不懂，或一眼看尽没兴趣 |

## 封面常见误区
- 把封面当"成品海报"塞满三个卖点 → 应只放一个钩子，信息留给内页。
- 白字压浅底、黄底白字、蓝底红字这类低对比 → 缩略图直接失效。
- 底部堆字、右上角堆字 → 被平台标题区与图标遮挡。
- 精致但无信息差/情绪/反差的"美图" → 好看但不被点（点击靠"和我有关 + 一点未知"）。
