# 单图共性特征：好看 / 高点击 / 高停留（可判定）

每个维度都给「合格」与「不合格信号」，能一眼对照判断。阈值是经验起点，按平台与人眼校准。

| 维度 | 合格判定 | 不合格信号 |
|---|---|---|
| **构图** | 有明确主轴（居中/三分/对角/上下分层任一成立）；水平线不歪；主体不被边缘切断；前/中/后至少两层；四角无抢眼杂物 | 画面散无主轴；主体贴边或切头切尾；背景线条穿主体；四角都有干扰物 |
| **视觉焦点** | 3 秒内能指出唯一主焦点；焦点在清晰度/对比/面积上至少一项最高；次焦点 ≤2 且弱于主焦点 | 多主体等权；第一眼不知看哪；焦点在死角；文字与主体同强度抢 |
| **色彩与明度** | 主色 ≤3、点缀 ≤1；主体与背景明度差 ≥2 档；色温统一；缩略下不糊成一片 | 大面积相近中灰；高饱和撞色；每块都在喊；主体与背景融在一起 |
| **信息密度** | 首图等权元素 ≤3 组、总 ≤5 组，每个元素有功能；内页可中高密度但分区 ≤3；密度高低交替 | 碎屑多/贴纸多/装饰多；元素互不相让；满屏无主次；连续多张都满 |
| **留白** | 主体至少一侧有呼吸区（≥短边 5–10%）；文字块四周留白 ≥0.5–1 倍字高；边距统一 | 四边贴满；文字顶边压角；留白成死角；主体挤在角落 |
| **缩略图可读性** | 缩到手机列表尺度仍能辨主体轮廓/主标题/主色块；眯眼或远看仍成立；去掉细节仍成立 | 缩略糊灰乱；主文字小到不可读；主体 <画面 1/5；靠细节才成立 |
| **真实可信感** | 光向一致、有接触阴影、材质纹理可见、透视比例合理、环境有合理痕迹；不过曝不塑料 | 主体像悬浮；光从左来影往右；背景与主体光不一致；过度磨皮/锐化/过曝；比例异常 |
| **图文关系** | 文字不压主体关键部位；文字与底有明度/色相差；文字补充画面而非重复画面（图文互证） | 字压脸/压关键细节；字与底同明度；图上已明显还写一遍；文字只是装饰噪音 |

## 一句判据
一张合格的图至少做到：**一眼看懂是什么（点击），再值得多看一眼（停留）**。前者靠"缩略图识别 + 一点未知"，后者靠"层次细节 + 信息递进"。
