# 图上文字：可读性、扫读路径、信息层级

图上有标题/标签/说明时，按下面的通用原则排，保证缩略图也读得清、视线不迷路。

## 扫读路径
固定为 **主焦点 → 主标题 → 副信息 → 细节**；每张只设**一个主信息**。从上到下、从左到右，主标题优先落在画面上半区（信息流先扫到）。路径步数 ≤2–3。

## 信息层级（≤3 级）
- 主标题 > 副标题 > 正文/标签；层级最多 3 级，别更多。
- 用**字重、字号、颜色、留白**做层级，不靠堆装饰。
- 主标题字高 ≥ 正文 1.6 倍；标签小于标题，不抢主标题权重。

## 文字体量与位置
- 主标题 ≤2 行；正文 ≤3–4 行；行宽 ≤画面 80%；行距 ≈1.2–1.5。
- 文字块面积：首图 ≤画面 ~20%，内页 ≤~30%。
- 文字距边 ≥3–5%；四周留白 ≥0.5–1 倍字高；不贴边、不压角。
- 文字集中在留白区/顶部/底部，不四处散落。

## 压图规则（文字压在画面上时）
- 必须有底：暗遮罩 / 亮遮罩 / 纯色留白区 / 局部压暗，任选其一；衬底只包裹对应文字块，别铺满整图。
- 文字与底对比 ≥4.5:1（大字号 ≥3:1）。
- 不压主体关键部位：眼、脸、产品核心、对比结果物，不压视觉焦点。
- 避开底部标题区与右上角平台图标（会被 UI 遮挡）。

## 图文不重复
画面已经表达清楚的，文字不再写一遍；文字只给**画面没有的**结论、条件、顺序或对比（图文互证，不互抄）。

## 判定测试（逐条过）
- [ ] 眯眼 1 秒能读出主标题？
- [ ] 缩略图尺度能读出主信息？
- [ ] 遮住文字，图仍成立？
- [ ] 遮住图，文字仍成立？
- [ ] 3 秒内能说出"主—次—辅"？
任一条不过，就是层级或压图出了问题，按上面改排版，别靠"再加点装饰"补救。
