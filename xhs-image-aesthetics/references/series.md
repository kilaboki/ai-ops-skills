# 一组图：成套、统一、看着舒服

封面 + 多张内页要"像同一套"，靠的是反复出现的**视觉语法**，不是每张单独好看。

## 可判定的统一规律

| 系统 | 统一做法 |
|---|---|
| 色彩系统 | 1 主色 + 1 辅色 + 1 强调色贯穿所有图；背景同族或同明度区间；饱和度/明度不逐张跳；色温统一 |
| 字体与字重 | 标题 1 种字体、正文 1 种字体；字重 ≤3 级；标题:正文 ≈ 1.6–2 : 1；行距字距固定 |
| 版式网格 | 同边距、同标题位置、同对齐线、同留白比例；封面强、内页稳；不每张换版式逻辑 |
| 视觉节奏 | 强对比封面 → 中密度信息 → 细节 → 总结；密度高低交替，**不连续多张满屏**（会视觉疲劳） |
| 风格一致 | 光向一致、色调一致、质感一致、图形元素一致；构图可变，但"语法"不变 |
| 系列锚点 | 统一角标、统一编号方式、统一标签样式（每页都有的小固定件） |

## 系列识别测试（一眼看是否"同一套"）
- 九宫格排开，像不像一组？
- 遮住文字，画面是否仍统一？
- 任意两张并排，会不会打架？
- 单张抽走，还能不能认出是这个系列？

## 为什么统一能提升停留与关注
降低滑动时的**认知切换成本**（大脑不用每页重新适应新规则）→ 延长单篇停留；形成**稳定预期** → 用户快速判断"这个账号持续给同类视觉收益" → 专业感 + 关注理由。一套图的节奏本身也是统一的一部分：读者滑到感受到的是同一套叙事语法，而不只是同一组颜色。

## 分工（封面/内页各自的任务）
- 封面 1 张：只负责"让人停下来"，单一焦点 + 一个钩子（见 `cover.md`）。
- 内页按**认知路径**排（痛点 → 过程 → 细节 → 对比/结果 → 总结），不按"卖点清单"排；每张只推进一个信息，别每张重复封面那句。
